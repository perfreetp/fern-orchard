# 中庭天窗日光光斑模拟（Babylon.js）

一座带通高中庭的三层小楼：屋顶是可开合的天窗叶片阵列，中庭侧墙为玻璃幕墙。
拖动时间轴改变太阳方位与高度，阳光穿过叶片缝隙在中庭墙面和地面投出条状光斑；
改变叶片开合角，光束宽度随之变化、光斑被切割并整体偏移；把某块玻璃点成镜面，
光斑会折到对面墙；当太阳高度使入射角逼近玻璃临界角时，光斑按 Fresnel 规律变暗并分裂。

## 物理简化约定

- 叶片简化为平板，在垂直于叶片长轴的二维剖面内做精确光线求交，再沿长轴（z）挤出。
- 只计算一次反射（镜面），忽略多次反弹。
- 玻璃能量用 Schlick Fresnel 近似：`R = r0 + (1-r0)(1-cosθ)^5`，普通玻璃 r0≈0.04。
- 叶片开合角 α：0° 水平闭合（板缘相接、开孔率 0），90° 竖直全开（开孔率最大）。
  缝隙有效宽度正比于 `sinα`，因此光束宽度、光斑条带宽度随 α 单调变化。

## 目录结构

```
index.html            入口与 UI（时间轴/开合角滑块、预置时刻按钮、HUD）
src/geometry.js       纯几何/物理引擎（无 Babylon 依赖，可在 Node 直接测试）
src/scene.js          Babylon 建模、材质、动态光斑网格、镜面点选、相机
test/geo.test.js      22 项物理对应关系测试
test/scene.headless.js 13 项渲染更新循环测试（mock BABYLON/DOM）
test/server.js        本地静态服务器
```

## 运行

```bash
node test/server.js          # 然后浏览器打开 http://localhost:8123/
```

支持 URL 参数定位状态，便于演示/截图：

- `?hour=17.8&angle=60` 指定时刻（8–18 时）与叶片角（0–90°）
- `&cam=alpha,beta,radius` 覆盖相机方位

## 操作

- 时间轴滑块：太阳方位/高度连续变化，预置「正午」「傍晚」两个时刻。
- 叶片开合滑块：0° 闭合到 90° 全开，观察光束被切割、条状光斑整体偏移。
- 鼠标点击东西幕墙任意玻璃面板：切换为镜面（再点恢复），镜面把光斑折向对面。
- 拖拽旋转视角、滚轮缩放；南墙做了半透明剖面处理方便观察室内。

## 验证的关键对应关系

- 闭合（α=0）无直射光斑；全开出现与通光缝隙一一对应的条状光斑。
- 光束宽度随 `sinα` 变化；板缘移动导致墙上光斑整体偏移。
- 正午光斑在地面，下午随太阳降低单调爬上对面东墙墙顶。
- 掠入射（θ≈84°）时 T 降到约 0.42（变暗）、R 升到约 0.58，反射斑与透射斑同时存在即分裂。
- 镜面一次反射把东墙光斑折向地面/西墙（对面）。
